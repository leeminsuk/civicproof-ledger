# CivicProof Ledger — 시연영상 가이드 (160초 원테이크)

> 2026 오픈소스 개발자대회 결과보고서 제출용. v1.1.0부터 시연은 **오토파일럿 모드**가 대신한다.
> 버튼 한 번이면 4막 전체가 자동 진행되고, 화면 하단 자막이 "지금 무엇이 실행 중인지, 그 역할이
> 무엇인지, 다음에 무엇을 하는지"를 해설한다. 내레이션 녹음이 필요 없다.
> 총 길이 160초(2:40)로 대회 기준 3분 이내에 들어온다.

---

## 방법 A — 완전 자동 녹화 (권장, 손 댈 것 없음)

```sh
npm ci            # 최초 1회
npm run record:video
```

- 약 3분 뒤 `~/Downloads/civicproof-autopilot-160s.webm` 과 `.mp4` (1920x1080) 가 생긴다.
- 코드가 브라우저를 띄워 오토파일럿을 실행하고 그대로 녹화한 것이므로, 편집 없이 유튜브에 올리면 된다.
- 확인 포인트: 영상 끝의 피날레 카드에 `수리 4 · 차단 1 · 12/12 · CII 100 · MATCH · PII 0` 이 보이는지.

## 방법 B — 직접 화면 녹화 (선택)

| 항목 | 권장 |
|------|------|
| 화면 녹화 | macOS 화면기록(⇧⌘5) 또는 OBS. 1080p·30fps 이상 |
| 화면 | 라이브 데모 <https://leeminsuk.github.io/civicproof-ledger/> 또는 로컬 `python3 -m http.server 4173 --directory web` |
| 준비 | 브라우저 폭 1280px 이상, 배율 100%(⌘0), 녹화 전 새로고침 1회 |
| 실행 | 녹화 시작 → 히어로의 **[160초 자동 시연]** 버튼 클릭 → 2:40 동안 대기 → 피날레 카드 2~3초 보여주고 녹화 종료 |

수동 녹화에서도 조작은 버튼 클릭 한 번뿐이다. 나머지는 오토파일럿이 스크롤·실행·해설을 전부 수행한다.

## 오토파일럿이 자동으로 보여주는 것 (타임라인)

| 구간 | 막 | 화면에서 일어나는 일 |
|------|----|--------------------|
| 0:00–0:18 | 1막 문제 정의 | 히어로 애니메이션(신원 입자→해시 방벽→널리파이어), 온체인 개인정보 0필드 KPI 스포트라이트 |
| 0:18–1:12 | 2막 원장 시뮬레이터 | 시민 3명이 사업 3종에 신청(수리 4·중복 차단 1), 시민 A의 사업별 널리파이어 비교 하이라이트(교차 추적 불가) |
| 1:12–2:04 | 3막 공격 극장 | 레드팀 12종을 증빙→원장·프라이버시→증명→감사로그 순으로 실제 실행, 12/12 차단 |
| 2:04–2:32 | 4막 무결성 검증 | CII 100 게이지, 감사 로그 조작 주입→Replay-Verify가 탐지(60 WATCH)→복구(100 EXCELLENT), 상태 루트 대조 |
| 2:32–2:40 | 피날레 | 검증 요약 카드: 수리 4 · 차단 1 · 12/12 · CII 100 · MATCH · PII 0 + 저장소 URL |

자막 해설과 진행 HUD가 영상 내내 표시되므로 별도 자막·내레이션 작업이 필요 없다.
이 타임라인은 `web/autopilot.js`의 선언적 데이터이며 `tests/autopilot.test.ts`가 순서·시각·서사 밀도를 고정한다.
